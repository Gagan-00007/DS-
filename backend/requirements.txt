# NOTE ON INSTALLING face_recognition: its package metadata depends on the
# PyPI package literally named `dlib`, which has no prebuilt wheels and
# needs CMake + a C++ toolchain to compile from source. `dlib-bin` provides
# the same binary under the importable name `dlib`, but pip won't accept
# it as satisfying face_recognition's declared dependency — it'll still
# try to source-build `dlib` and fail on a missing/broken compiler.
#
# Fix: install in this exact order, do NOT just `pip install -r requirements.txt`
# for this section:
#   pip install dlib-bin
#   pip install --no-deps face_recognition face_recognition_models
#   pip install click Pillow numpy

# the literal `dlib` package once dlib-bin is already installed.
